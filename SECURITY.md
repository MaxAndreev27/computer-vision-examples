# Security Policy

## Supported Versions

This project is an educational repository. Security fixes are applied to the default branch when a valid issue is identified.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting or Security Advisories for this repository when available. Include:

- A clear description of the issue
- The affected file, cell, or dependency
- Reproduction steps or a minimal proof of concept
- Potential impact
- Any suggested mitigation

If private reporting is unavailable, contact a repository maintainer through a private GitHub channel before disclosing the issue publicly.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.
