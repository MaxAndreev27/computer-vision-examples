# Support

## Questions and Bug Reports

- Use the [bug report form](../../issues/new?template=bug_report.yml) for reproducible problems.
- Use the [feature request form](../../issues/new?template=feature_request.yml) for proposed examples or improvements.
- Search existing issues before opening a new one.

## Include Useful Details

When asking for help, include:

- Operating system and Python version
- Package versions from `requirements.txt`
- The notebook section or cell involved
- The exact error message
- Minimal reproduction steps
- A description of the expected and actual result

Do not upload private or sensitive images.

## Security Issues

Do not use public issues for security vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.
